# SKELETON — EveMark

Актуальная карта. Читать перед задачей. Обновлять в том же шаге, если меняются структура, схема БД, пороги доски или сигналов.

Локальное имя каталога: `C:\Code\jita-watch`. Сборка называется JitaWatch. Репозиторий: https://github.com/MerlKoryAmber/EveMark

## Статус
Локальный стол Jita 4-4 работает. Ордера только читаются, заявки не ставятся. Приёмку ставит человек.

Хвост: история ESI для type 62593 отвечает 400, тип не помечается `no_trade`, запрос повторяется.

## Запуск
Публикация: `dotnet publish JitaWatch.csproj -c Release -r win-x64 --self-contained false -o publish`. Перед этим остановить `JitaWatch.exe` (файл занят). Старт с рабочим каталогом `publish`. `publish\data` не удалять.

## Рынок
- Регион The Forge `10000002`, станция Jita 4-4 `60003760`.
- Снимок раз в час. В базе одна строка на тип: лучшая покупка = max buy, лучшая продажа = min sell.
- Объём и число ордеров — внутри 1% от лучшей цены. Покупка: цена ≥ bestBuy×0.99. Продажа: цена ≤ bestSell×1.01.
- Продажа дешевле 1 000 000 ISK не пишется.
- Вчерашний объём — дневная история The Forge за вчера UTC. Пустой или не вчерашний день на доске пустой. Оценка = маржа × min(вчера, объём на покупке, объём на продаже).
- Часы — подряд идущие снимки с маржой > 0 и обеими сторонами ≥ 2 шт. Разрыв > 90 минут рвёт серию.
- Деньги в UI целыми ISK. Объёмы, часы и проценты — как есть. Процент в фильтре как на экране: 5 = 5%. Фильтр от/до, пустая граница не режет. Страница 200.

## Комиссии
Налог 7.5%×(1−0.11×Accounting). Брокер 3%−0.3%×BrokerRelations−0.03%×фракция−0.02%×корп, пол 1%. По умолчанию Accounting V, Broker Relations V, стендинги 0. Хранятся в `setting`. Маржа = sell×(1−брокер−налог) − buy×(1+брокер). Перестановка в маржу не входит.

## Сигналы
Общий вход: маржа после комиссий 3–100%, вчерашний объём ≥ 10.

| Раздел | Условие |
|--------|---------|
| Крик | ≥ 6 снимков, часы ≥ 6, оценка ≥ 10 млн, вчерашняя средняя внутри спреда. Тонко: «покупка», если buy×2 < sell; «продажа», если sell×2 < buy |
| Мимо цены | Те же ворота, средняя вне спреда |
| Дёргают | ≥ 4 снимка. Лучшая покупка или продажа менялась каждый шаг, серия ≥ 3, смотрим до 5 шагов, разрыв ≤ 90 минут |
| Сжимается | Маржа > 0 и строго падает 3 часа подряд. «Маржа была» — маржа в начале падения |

Шарик трея только когда есть Крик.

## Что не грузится
`reject.reason`: `cosmetic` (одежда, краски, скины, ящики с ними), `no_trade` (история без сделок). Старые скины могут лежать как `skin`. `Unreject` снимает только `no_trade`.

Украшение (`CollectorService.IsCosmetic`): имя содержит ` SKIN`; начинается с `Men's ` / `Women's ` / `Camo`; содержит `Apparel` или `Cybernetic Arm`; отдельное слово Jacket, Boots, Suit, Beret, Goggles, Glasses, Mask, Outfit, Scarf, Shoes, Hoodie, Shirt, Pants, Dress, Skirt, Blouse, T-Shirt, Camo, Pattern, Patterns. Не режутся Target Painter, Cap Recharger, Coating, Sequencer, Yellowjacket, Suite, Boots.ini.

## База
SQLite WAL. Деньги в TEXT. Таблицы: `snapshot`, `quote`, `type_name`, `daily_history`, `history_sync`, `setting`, `reject`, `status`. Срок хранения 1–400 дней, по умолчанию 120 (`setting.keep_days`). Чистка после снимка без VACUUM. Сохранение настроек чистит и делает VACUUM.

## API
`GET /api/status`, `GET|POST /api/settings`, `POST /api/collect`, `GET /api/recommendations`, `GET /api/signals`.
