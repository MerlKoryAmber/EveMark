# Сигнал: скользящее окно 48 ч

## Зачем
После простоя ПК «Часов» обнулялись (разрыв > 3 ч), Крик/Мимо пустели — «тыква».

## Что сделано
- `SignalRule.Lookback` = 48 ч, `AverageDays` = 2.
- Ранний баннер: снимки **за 48 ч**, не за всё время.
- Часы в сигнале: `StreakRolling` — мёртвая вилка рвёт, простой без снимков нет; закуп по-прежнему `Streak` + `MaxHoursGap` 3 ч.
- Средняя в сигнале: VWAP ESI Forge за до 2 полных дней.
- Дёргают/сжатие: логика 90 мин без изменений (точки из окна 48 ч).
- UI/SKELETON/OPISANIE/handoff обновлены.
