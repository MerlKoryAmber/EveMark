# MK Jitawatch

Программа для станции Jita 4-4 в EVE Online. Показывает, где сейчас есть смысл купить дешевле и продать дороже. Ордера сама не ставит — только смотрит рынок и подсказывает человеку.

На экране и в трее называется **MK Jitawatch**. Файл программы — `JitaWatch.exe`.

## Кому это

Тем, кто торгует на станции и не хочет вручную перебирать сотни позиций. Не нужно быть профтрейдером: в разделе «Сигнал» у заголовков столбцов есть подсказки при наведении.

## Что умеет

- Раз в час снимает картину рынка The Forge по станции Jita 4-4.
- Считает маржу с учётом налога и брокерской (настройки можно поменять).
- Доска «Закуп» — список предметов с ценами, объёмом, оценкой за сутки и другими цифрами.
- Раздел «Сигнал» — короткие списки: «Крик» (есть шанс), «Мимо цены», «Дёргают», «Сжимается».
- Работает только на вашем компьютере. В интернет ходит к официальному ESI CCP, заявки не размещает.

## Как поставить

1. Скачайте архив с [страницы релизов](https://github.com/MerlKoryAmber/EveMark/releases).
2. Распакуйте папку целиком куда удобно.
3. Запустите `JitaWatch.exe`.
4. Если базы ещё нет — программа спросит, создать ли новую. Ответьте «Да».
5. В трее (возле часов) появится значок. Через него: «Открыть», «Сигнал», «Выход».
6. Страница откроется в браузере: `http://127.0.0.1:8741`.

.NET отдельно ставить не нужно: в релизе уже всё нужное для Windows 64-bit.

## Как пользоваться

- **Закуп** — основная таблица. Можно фильтровать и сортировать столбцы. Кнопка «Столбцы» прячет лишнее. Если столбцов много, таблица едет внутри окна, название предмета остаётся слева.
- **Сигнал** — короткие списки под разные ситуации. «Крик» ещё и всплывает из трея, когда есть подходящие позиции.
- **Настройки** — уровень Accounting, Broker Relations, стендинги и сколько дней хранить историю снимков.
- Ссылка на название предмета открывает карточку на EveTycoon.

Первый час после установки список ещё короткий: снимки копятся со временем. «Крик» смотрит на несколько часов подряд, поэтому сразу после старта там может быть пусто — это нормально.

## Важно

- Нужен Windows x64 и доступ в интернет к ESI.
- Копируйте на другой компьютер всю папку целиком, не один exe.
- База и журнал лежат рядом с программой в папке `data`. Их лучше не удалять, если не хотите начать с нуля.
- Это не совет по инвестициям и не бот для автоторговли. Решения и ордера — ваши.

## Для тех, кто собирает из исходников

Нужен .NET 8 SDK. В каталоге проекта:

```text
dotnet publish JitaWatch.csproj -c Release -r win-x64 --self-contained true -o publish
```

Перед сборкой остановите уже запущенный `JitaWatch.exe`. Живую папку `publish\data` при обновлении не стирайте.

Карта проекта для разработки: [docs/SKELETON.md](docs/SKELETON.md).
