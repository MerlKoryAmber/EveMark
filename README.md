# MK Jitawatch

Локальный стол для торговли в EVE Online. Смотрит рынок, считает маржу и подсказывает человеку, куда смотреть. Ордера сама не ставит.

На экране и в трее — **MK Jitawatch**. Файл программы — `JitaWatch.exe`.

Актуальная сборка: [релизы на GitHub](https://github.com/MerlKoryAmber/EveMark/releases) (сейчас **0.2.2**).

## Кому это

Тем, кто торгует на хабах и не хочет вручную перебирать сотни позиций. Не нужно быть профтрейдером: у заголовков столбцов в «Сигнале» и «Развозе» есть подсказки при наведении.

## Что умеет

- Раз в час снимает ордера по регионам хабов: The Forge, Amarr, Dodixie, Rens, Hek.
- Считает маржу с учётом налога и брокерской (настройки можно поменять).
- **Закуп** — доска для вилки на Jita и NPC-станциях Perimeter. Галками можно оставить только Jita или только Perimeter.
- **Сигнал** — короткие списки: «Крик», «Мимо цены», «Дёргают», «Сжимается». «Крик» всплывает из трея; отключается галкой «Оповещения о заработке» на иконке.
- **Развоз** — где выгодно купить чужой sell на одном хабе, отвезти и либо сразу продать в скупку, либо выставить свой sell. Хабы: Jita, Perimeter, Amarr, Dodixie, Rens, Hek. В развоз попадают позиции от 500 тыс. ISK.
- Работает только на вашем компьютере. В интернет ходит к официальному ESI CCP.

Рынки на цитаделях игроков в Perimeter пока без логина в EVE не подтягиваются — только NPC-станции Perimeter и Jita 4-4.

## Как поставить

1. Скачайте `MK-Jitawatch-win-x64.zip` с [страницы релизов](https://github.com/MerlKoryAmber/EveMark/releases).
2. Распакуйте папку целиком.
3. Запустите `JitaWatch.exe`.
4. Если базы ещё нет — согласитесь создать новую.
5. В трее (возле часов): «Открыть», «Сигнал», галка «Оповещения о заработке», «Выход».
6. Страница: `http://127.0.0.1:8741`.

.NET отдельно ставить не нужно: в архиве уже всё для Windows 64-bit.

## Как пользоваться

- **Закуп** — фильтры и сортировка по столбцам, кнопка «Столбцы», галки Jita / Perimeter. Широкая таблица едет внутри окна, название предмета остаётся слева.
- **Сигнал** — короткие списки под разные ситуации на рынке.
- **Развоз** — только плюсовые маршруты. Есть цена мгновенной продажи в скупку, цена выставления своего sell и маржа при этом, объём за сутки по региону назначения, прыжки, м³ за штуку. В фильтрах хабов можно писать `jita`, `amarr`, `rens` и т.п.
- **Настройки** — Accounting, Broker Relations, стендинги и срок хранения снимков.
- Ссылка на название предмета открывает карточку на EveTycoon.

Первые часы после установки списки ещё копятся. «Крик» смотрит несколько часов подряд — сразу после старта там может быть пусто.

## Важно

- Нужен Windows x64 и интернет до ESI.
- На другой компьютер копируйте всю папку, не один exe.
- База и журнал — в папке `data` рядом с программой. Не удаляйте, если не хотите начать с нуля.
- Это не совет по инвестициям и не бот для автоторговли. Решения и ордера — ваши.

## Для тех, кто собирает из исходников

Нужен .NET 8 SDK:

```text
dotnet publish JitaWatch.csproj -c Release -r win-x64 --self-contained true -o publish
```

Перед сборкой остановите `JitaWatch.exe`. Папку `publish\data` при обновлении не стирайте.
